# MODUL 13 - Flutter CRUD REST API

## Deskripsi
Aplikasi praktikum Modul 13 menggunakan Flutter dan Dart untuk melakukan operasi CRUD (Create, Read, Update, Delete) melalui REST API.

## Fitur
- Menampilkan data dari REST API.
- Menambahkan data baru.
- Mengubah data.
- Menghapus data.

## Teknologi
- Flutter
- Dart
- HTTP Package
- JSONPlaceholder REST API

## Cara Menjalankan
1. Clone repository ini.
2. Jalankan `flutter pub get`.
3. Jalankan aplikasi dengan perintah:

```bash
flutter run -t lib/main_modul13.dart
```
